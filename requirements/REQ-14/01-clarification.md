# REQ-14 澄清记录

## 需求概述

构建一个项目管理界面,以**卡片网格**形式展示**项目列表**。

## 关键约束(已与需求方确认)

| 维度 | 决定 |
|------|------|
| 目标仓库 | `https://github.com/renqianqian/project-demo` |
| 技术栈 | **React 18 + Vite**(原生 CSS,无 UI 库) |
| 数据源 | **全部 mock**,不接后端、不请求任何 API |
| 字段范围 | 每个项目仅含 **项目 ID(`id`)** 与 **项目名称(`name`)** |
| 是否含人员 | **否**(不含负责人 / 成员 / 协作人) |
| 交互范围 | **只读列表**,无新建 / 编辑 / 删除 |
| 列表样式 | **卡片网格**(CSS Grid `auto-fill, minmax(220px, 1fr)`) |

## 未覆盖项(暂不实现,如需后续可追加)

- 搜索 / 筛选 / 排序
- 分页(数据量小,不必要)
- 项目详情页 / 跳转
- 状态、负责人、创建时间、截止时间等其他字段
- 任何后端 API / 持久化

## 与需求方的约定

- 分支命名:`req/REQ-14/main`,基于 `project-demo` 仓库的 `main` 创建。
- 启动方式:`npm install && npm run dev`,访问 `http://localhost:5173`。
- 数据文件位置:`src/data/projects.js`(便于人工扩展 mock)。
